# Installing Spooly on Windows

1. Download the [Windows installer](https://github.com/rdcstout/Spooly-by-Extrusion-Therapy/releases/latest/download/Spooly-Setup-Windows-x64.exe).
2. Close Spooly if it is running, then run the installer.
3. Open Spooly and add your printers in Setup.

The Windows installer is unsigned, so Windows SmartScreen may display a warning. Verify that the file came from the official release before choosing to run it.

For printer connection help, see the [Bambu](BAMBU_SETUP.md) or [Klipper / Moonraker](KLIPPER_SETUP.md) setup guide.
