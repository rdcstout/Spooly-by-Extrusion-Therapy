Connect a Bambu printer

Leave the printer in its normal stock/cloud mode first. Spooly only talks to it on your local network.

  1. Use the same network. Your Mac or PC and printer must be connected to the same home network. Avoid guest Wi-Fi.
  2. Click Scan local network. Select your printer. Spooly fills in its name, IP address, and serial number automatically.
  3. Find the access code. On newer Bambu printers, open Settings → LAN Only. Read the access code shown on that page, but do not turn LAN Only on. On older interfaces, open Settings → Network/WLAN → LAN Only Mode.
  4. Enter the code and connect. Copy the code exactly, click Save & connect, and wait for the success message.
Opening the LAN Only page does not enable LAN Only mode. Spooly normally works while the printer remains in its stock, cloud-connected mode. Only change the mode if troubleshooting specifically requires it.

If Scan finds nothing: enter the IP and serial manually. On an X1C, the serial is under Settings → General → Device Info or Device & Serial Number.
